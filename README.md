## Description
A web based IT Help Desk for an organisation (school, office or lab). Stuff, Students and  users report hardware and software problems as tickets. Technicians work on assigned tickets and record solutions. The administrator oversees all tickets, assigns technicians, changes status and manages categories.

## Pages
| Page | Purpose |
|---|---|
| `index.html` | Public landing page with hero, features and Login/Register buttons |
| `login.html` | Login with role selection (User / Technician / Admin) |
| `register.html` | New user registration |
| `user-dashboard.html` | User stats and "My Tickets" table (View / Edit / Cancel) |
| `report-problem.html` | Form to create a new ticket |
| `technician-dashboard.html` | Technician stats, assigned tickets and quick status/solution update |
| `admin-dashboard.html` | System stats, tickets by priority, full table with Assign / Status / Delete |
| `tickets.html` | Full ticket list with search and filters |
| `categories.html` | Admin page to manage ticket categories |
| `view-ticket.html` | Full ticket details, status badge, solution and role actions |
| `edit-ticket.html` | Pre-filled edit form for a Pending ticket |
| `style.css` | Shared stylesheet for every page (in `pages/`) |

## How to View
Open `index.html` (or `pages/index.html`) in any modern web browser. No server or installation is needed. On the login page use the demo links to reach each dashboard.
