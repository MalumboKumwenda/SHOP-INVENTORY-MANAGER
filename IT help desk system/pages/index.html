How a ticket moves

Every request passes through the same four stages, and you can see where yours is at any time.

  1. Pending

    Request logged

    Your ticket is recorded and waits for review.

  2. Assigned

    Technician assigned

    A member of the support team takes ownership.

  3. In Progress

    Work under way

    The technician diagnoses and fixes the issue.

  4. Resolved

    Solution recorded

    The fix is added to your ticket for reference.

What we can help with

Pick the category that fits when you submit a ticket.

  • Software

  • Network
